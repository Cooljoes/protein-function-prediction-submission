# Protein Function Prediction Submission

This repository contains a CSV submission file for protein function prediction.

## File

- `submission_GO_V25_fusion_048145.csv` — predicted labels for protein identifiers. The file contains one `protein_id` column and 500 label columns.

## Format

The CSV header is `protein_id` followed by `label_0` through `label_499`. Rows contain protein IDs and binary label values.
